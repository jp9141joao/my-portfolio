# Portfolio

Personal portfolio website of **João Pedro Rosa de Paula**: Software Engineer focused on automation, full-stack development and network observability.

## Sections

- Hero with introduction
- About me
- Skills

## Tech stack

- Next.js (App Router) and React
- TypeScript
- Tailwind CSS
- Radix UI primitives, shadcn/ui-style components and Embla carousel
- React Icons and Lucide

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project structure

```
src/
  app/          layout, global styles and home page
  components/   Navbar, hero, aboutMe, skills and shared UI
  lib/          utilities
  assets/       images
```
